# process — how to work in this repo: tests, CI asks, review routing

Full hooks for this area. The routing keys live in `../MEMORY.md`.

- [Flakes get a dedicated PR merged first](../feedback_directus_flakes_get_dedicated_pr.md) — rerun the shard + parallel root-cause fix PR before the feature PR (#602)
- [Amending the prior commit is OK on this feature branch](../feedback_amend_ok.md) — for upstream-bound PR work, prefer `git commit --amend` + `git push --force-with-lease` over layered fix-up commits
- [Don't ask before pnpm install / build in this repo](../feedback_no_ask_for_build_install.md) — project override of the global ask-before-install rule; routine install/build steps run silently, dep-modifying commands still ask
- [Never run blackbox locally — run it in CI](../feedback_directus_bb_tests_in_ci.md) — local is SLOWER (full dist deploy + a server per env variant, no sharding) and re-seeds jean's docker stack; push, open the PR (no label needed), loop on the run
- [New feats base on v11.10.1-hhh-dev](../feedback_directus_new_feat_base_hhh_dev.md) — hhh-dev is now THE work branch for new features (no more v11.10.1-feat/* chain branches); always `git fetch` + sync hhh-dev to its tip before starting a feat
- [Never reset --hard a dirty tree](../feedback_never_reset_hard_dirty_tree.md) — cleaning a --no-commit dry-run with reset --hard nukes pre-existing unstaged mods (no blob → unrecoverable); use --abort / scoped restore; recover via sibling-branch blobs or session-transcript Edit/Write content
- [A bad env var fails the boot](../feedback_directus_bad_env_var_fails_boot.md) — exit before listen, message names the var + what's wrong; never fall back to the default; unset optional = default; check how @directus/env casts it first
- [85-col cap on .liquid too](../feedback_directus_liquid_85_col.md) — jean wants the width gate on .liquid env templates; wired via a no-op-parser block in eslint.style.config.js + `*.liquid` in the gate globs (max-len only, line-based) — not manual
- [Re-dispatch the admin preview without asking](../feedback_directus_redispatch_preview_freely.md) — after a push, fire `preview-admin.yml` on the FEATURE branch's ref immediately; cancelling the live tunnel is wanted, not a confirmation-worthy side effect; never PATCH the PR body right after a push (the `edited` run cancels the in-flight preview then skips); hand over `<url>/auto-login`, never the bare tunnel url
- [The admin preview is not a CI check](../feedback_directus_ci_watch_skip_preview.md) — meant to run until its worker timeout or until a newer preview supersedes it; never wait on it AND never mention it in a CI report whatever state it is in (not even as an exception); judge on Check/Style/CodeQL, read the URL from the PR description
- [Postgres only in the main workflow](../feedback_directus_pg_only_dialect_focus.md) — don't invest in MariaDB/SQLite for now (revisit in months); the bb PR matrix is already postgres-only by design, so never report their absence as a gap
- [Non-PG review points go to #610](../feedback_directus_non_pg_review_points_to_610.md) — sqlite/cockroach/maria-only finding → new point in issue #610 + `TODO(#610):` comment, never fixed in the PR; standing ruling, no need to ask
- [Diverging from upstream files is fine here](../feedback_directus_diverge_from_upstream_freely.md) — "it would touch a pristine upstream file" is NOT a reason to decline a fix; AGENTS.md's minimal-diff rule is about not reformatting untouched lines
- [Run the gates of the repo you edited](../feedback_run_the_gates_of_the_repo_you_edited.md) — fork/consumer habits don't transfer (a consumer's lint wants other rules); `node --check` is not a lint gate; never copy style from a commented-out line
- [Run every test in CI, loop on the run](../feedback_directus_ci_only_test_runs.md) — unit, typecheck and blackbox all in CI; no local vitest or `tsc` gate (the local api suite is 400s and has 5 permanently-red environmental files)
- [CI-triggering action needs its own approval](../feedback_ci_trigger_needs_own_approval.md) — label/dispatch/rerun is its own ask, never implied by "merge once green"; unanswered offer = no
- [Read a memory's body, not just its filename](../feedback_memory_body_over_filename.md) — a stale slug can say the opposite of the current body; refused already-granted work by reading only the filename
- [Never write legacy/outdated-need comments](../feedback_no_legacy_comments.md) — no "used to"/"no longer"/"deliberately not"; state what's true now, reasoning belongs in the commit
- [New bb files are Gherkin](../feedback_directus_blackbox_gherkin_standard.md) — every new blackbox test = `.feature` + step `.test.ts` (loadFeature/defineFeature); plain describe/it is legacy; copy a sibling's .feature, not only its spawn code
- [Main tree stale WIP (cleaned)](../project_directus_main_tree_stale_wip.md) — Sept stash-pop WIP worthless, parked in tmp/main-tree-wip-2026-09/; main-tree memories drift from hhh-dev, diff `.agents` before committing them
- [No consumer data in fork memories](../feedback_directus_no_consumer_data_in_fork_memories.md) — repo is public: a consumer host/service/table/email/issue goes to the consumer's private repo; here only "a consumer"
